# SA Language Switcher

[English](README.md) · Русский

**SA Language Switcher** добавляет языковые пакеты в штатное меню **Options → Language** игры GTA San Andreas 1.0 US Hoodlum. Можно оставить английский и испанский и добавить рядом русский или другой перевод. Для каждого пакета задаются собственный файл текста, метрики шрифтов и текстуры.

Репозиторий содержит исходники и шаблон настроек. Файлы переводов и шрифтов пользователь добавляет отдельно.

## Как это работает

- ASI добавляет строки в активную таблицу меню GTA. Игра сама рисует пункты, расставляет их с обычным интервалом и обрабатывает навигацию.
- При выборе пакета игра загружает его GXT, а плагин подставляет пары метрик и текстур в два штатных слота шрифтов. При возврате к штатному языку восстанавливается набор шрифтов, который использовался до переключения. Если установлен другой шрифтовой мод, плагин сохраняет именно действующий набор.
- Выбор вступает в силу сразу и сохраняется в разделе `[Selection]` файла `LanguageSwitcher.ini`. При следующем запуске плагин применяет сохранённый пакет после инициализации меню.
- В меню помещается до шести дополнительных языков. Количество доступных строк зависит от разметки экрана Language.

## Установка

1. Поместите `LanguageSwitcher.asi` и `LanguageSwitcher.ini` в одну папку. При обычной загрузке ASI подойдёт корневая папка игры или `scripts`. Для Mod Loader 0.3.10 используйте отдельную папку внутри `modloader`. Установите одну копию ASI.
2. Укажите пути к своим GXT, DAT и TXD в INI. Каждый относительный путь сначала проверяется от папки ASI, затем от папки игрового EXE. Можно использовать абсолютные пути.
3. Запустите игру и выберите язык в **Options → Language**.

Для русского языка в шаблоне уже есть пример:

```ini
[Language.Russian]
MenuLabel=Russian
NativeMenuLabel=Русский
TextFile=text\russian.gxt
FontMetricsFile=data\fonts_ru.dat
FontTextureFile=models\fonts_ru.txd
```

Эти пути рассчитаны на соответствующий пакет **Russian Localization Support**. Перед переключением строка называется **Russian**. Когда русский пакет активен, игра выводит **Русский** шрифтом этого пакета.

## Как добавить другой язык

Создайте секцию `[Language.<ID>]` с уникальным постоянным ID и укажите свой комплект файлов. Например, для польского пакета это может выглядеть так:

```ini
[Language.Polish]
MenuLabel=Polish
NativeMenuLabel=Polski
TextFile=text\polish.gxt
FontMetricsFile=data\fonts_pl.dat
FontTextureFile=models\fonts_pl.txd
```

| Параметр | Что указать |
| --- | --- |
| `MenuLabel` | Подпись для неактивного языка, которую сможет отобразить текущий шрифт. Используйте печатные ASCII-символы. |
| `NativeMenuLabel` | Подпись для активного языка. Пустое значение или неподдерживаемые символы оставляют `MenuLabel`. Плагин поддерживает ASCII и кириллицу в кодировке русского пакета из примера. Для других алфавитов собственная кодировка подписи пока не предусмотрена. |
| `TextFile` | GXT для ПК-версии GTA SA с 8-битным игровым текстом. Плагин проверяет структуру основных и миссионных таблиц перед загрузкой. |
| `FontMetricsFile` | DAT с секциями `[FONT_ID]` 0 и 1. Для каждой нужны 208 значений `[PROP]`, а также `[UNPROP]` и `[REPLACEMENT_SPACE_CHAR]`. |
| `FontTextureFile` | TXD с текстурами `font2` для слота 0 и `font1` для слота 1. Раскладка глифов должна соответствовать байтам текста в GXT и метрикам в DAT. |

Порядок секций можно менять. Сохранённый выбор привязан к ID, поэтому при переименовании секции потребуется выбрать язык заново.

## Совместимость и диагностика

Целевая версия — **GTA San Andreas 1.0 US Hoodlum (x86)**. Без Mod Loader плагин использует штатную таблицу меню. С Mod Loader 0.3.10 он находит перенесённую таблицу и сохраняет существующую обработку GXT для штатных языков. ASI работает с текстом и меню GTA. Чат и диалоги клиента SA-MP остаются вне области его работы.

В разделе `[General]` установите `Enabled=0`, чтобы отключить переключатель. Параметр `EnableLogging=1` включает журнал `LanguageSwitcher.log` рядом с ASI. Журнал начинается заново при каждом запуске и содержит определённую версию игры, ошибки пакетов и адреса проверяемых хуков. Для неподдерживаемых версий и несовместимых точек перехвата ASI оставляет игру без своих хуков.

## Сборка из исходников

Понадобятся Visual Studio 2022 Build Tools, набор MSVC v143 с поддержкой x86 и Windows SDK. Выполните команды в папке репозитория:

```powershell
git clone https://github.com/DK22Pac/plugin-sdk.git
git -C plugin-sdk checkout 15f15b60bbf74c106e1b496ff92c98764abf4605
.\build.ps1 -PluginSdk .\plugin-sdk
```

Можно указать путь к уже существующей копии plugin-sdk через `-PluginSdk`. Если SDK лежит рядом с папкой проекта, достаточно запустить `.\build.ps1`. Скрипт собирает `LanguageSwitcher.asi` в режиме Win32 Release и проверяет архитектуру и зависимости через `dumpbin`.
